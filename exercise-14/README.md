# Lab Exercise 14: Pair Collaboration, Feature PRs & Contributing Guide

> **Objective**: Simulate collaborative open-source team workflows using isolated feature branches, pull requests on GitHub, peer reviews, and establishing a formal `CONTRIBUTING.md` guideline.

---

### Step-by-Step Workflow

1. Spawn dedicated collaboration branch:
   ```bash
   git switch -c feature/collaboration-docs
   ```
2. Draft and commit `CONTRIBUTING.md` featuring branching protocols, commit formatting rules, and peer review sign-off checklists.
3. Push branch to remote and submit Pull Request #4 on GitHub.
4. Simulate peer approval and merge the feature branch cleanly into `main`.
